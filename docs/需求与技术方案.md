# 美食城外卖点餐平台 — 需求与技术方案

> 版本：v1.0（骨架阶段定稿）
> 后端技术栈依据：`编码规则模板-AGENTS.md`

## 1. 项目概述

面向**附近写字楼上班族**的微信小程序外卖点餐平台。业务单位为**美食城/商圈**，美食城内入驻多个**档口（商家）**，用户在用户端小程序按档口点餐、跨档口购物车结算，商家在商家端小程序接单出餐并自行配送至用户工位。

## 2. 角色与客户端

| 角色 | 客户端 | 职责 |
|---|---|---|
| 用户 | 用户端小程序 | 浏览美食城/档口/菜品、购物车、下单、支付、订单跟踪、评价、收藏、优惠券 |
| 商家（档口） | 商家端小程序 | 档口信息、菜品管理、接单/出餐/完成、订单列表、评价查看、日营收统计 |
| 平台运营 | 无（暂不做管理后台） | 首版靠商家端小程序 + 数据库/脚本运营 |

## 3. 已确认的关键决策

- **业务模型**：美食城 `mall` → 档口 `shop` → 菜品 `dish`。
- **跨档口购物车**：一次结算跨多个档口时，**按档口自动拆分为多个子订单**（各自接单配送），对应一个支付单；用户端只感知"一次支付、多个子单"。
- **配送**：商家自行配送；**每个档口固定配送费+起送价**；用户填写字楼公司+楼层+工位。
- **支付**：**首版模拟支付**（stub 回调），**预留真实微信支付适配层**；获取商户号后可替换。
- **首版功能**：登录 · 浏览 · 购物车 · 下单 · 支付 · 订单跟踪 · **评价** · **优惠券/满减** · **收藏+再来一单**。
- **购物车存储**：小程序本地缓存，下单时后端校验，不建 cart 表。

## 6. 数据表设计（草案，约 15 张）

通用字段（每表）：`id bigint` 主键、`create_time`、`update_time`、`deleted`（逻辑删除，`@TableLogic`）。所有表/字段写注释，索引每表 ≤5。

### 主数据
**mall（美食城/商圈）**：`name` 名称、`address` 地址、`longitude`/`latitude`、`cover_img` 封面、`business_hours` 营业时间、`status` 状态(0关闭1营业)。

**shop（档口/商家）**：`mall_id`、`name`、`logo`、`phone`、`delivery_fee` 配送费、`min_order_amount` 起送价、`average_delivery_time` 预计送达分钟、`business_hours`、`status`。

**dish_category（菜品分类）**：`shop_id`、`name`、`sort`。

**dish（菜品）**：`shop_id`、`category_id`、`name`、`image`、`price`、`original_price` 原价(划线价)、`description`、`status`(0下架1上架)、`sort`、`sold_count`。

**dish_spec（规格/口味）**：`dish_id`、`name`、`price`（可空：加价）。非必需时可选。

**user（用户）**：`openid`(唯一索引)、`nickname`、`avatar`、`phone`、`status`。

**user_address（用户地址=写字楼）**：`user_id`、`contact` 联系人、`company` 公司、`building` 楼栋、`floor` 楼层、`office` 工位/房号、`phone`、`is_default`。

### 营销
**coupon（券模板）**：`name`、`type`(1满减2折扣)、`threshold` 使用门槛、`amount` 减免额/折扣、`total_count`、`remain_count`、`start_time`、`end_time`、`shop_id`(空则平台通用)。

**user_coupon（用户领券）**：`user_id`、`coupon_id`、`status`(0未用1已用2过期)、`use_time`。

### 交易（跨店拆单）
**payment（支付单）**：`payment_no`(唯一)、`user_id`、`total_amount` 总额、`channel`(1模拟2微信)、`status`(0待支付1成功2失败/取消)、`pay_time`、`transaction_id` 微信流水。

**order（子订单·按档口拆分）**：`order_no`(唯一)、`payment_id`、`user_id`、`shop_id`、`status`(见状态机)、`total_amount` 商品总额、`delivery_fee`、`discount_amount` 优惠金额、`pay_amount` 实付、`address_snapshot` 收货信息快照、`remark`、`delivery_time`/`finish_time`。

**order_item（订单项·快照）**：`order_id`、`dish_id`、`dish_name`、`spec_name`、`dish_image`、`price` 当时单价、`count`、`amount`。

**order_coupon（订单用券）**：`order_id`、`user_coupon_id`、`amount`。

### 互动
**order_comment（评价）**：`order_id`、`user_id`、`shop_id`、`score`(1-5)、`content`、`images`。
**favorite（收藏）**：`user_id`、`shop_id`、`type`(预留菜品)、唯一索引(user_id,shop_id,type)。

> 建表 SQL 后续写入 `docs/sql/*.sql`（AGENTS 第六节），本地 Navicat 改表禁止。

## 7. 订单状态机（子订单）

```
待支付(0) → 已支付/待接单(1) → 备餐中(2) → 配送中(3) → 已完成(4)
       ↘ 已取消(5)   →（可含售后 6/退款，二期）
```
- 支付单全部子单创建后，任一子单扣款成功 → 支付单成功。
- 各子订单独立流转（商家各自接单、出餐、完成）。

## 8. 拆单设计（核心点）

1. 下单入参为跨档口的 `items`（dishId + count + spec + 优惠券）。
2. 后端按 `dish.shop_id` 分组，校验各档口**起送价**、库存、档口营业状态。
3. 计算各档口子订单金额（商品额 + 配送费 − 优惠按档口分摊），汇总为支付单金额。
4. **一个事务**内：创建 `payment` + 多个 `order` + `order_item`，扣减库存、核销优惠券、累加销量。
5. 返回支付单号 → 用户支付（模拟/真实）→ 回调成功后各子单置为"待接单"。

## 9. 接口清单

鉴权：除 `/auth/login` 外全部需携带 `Authorization: Bearer <jwt>`，失败返回 401 统一体。

| 模块 | 接口 | 说明 |
|---|---|---|
| auth | POST /auth/login | 微信登录 code→openid→jwt |
| user | GET/POST/PUT/DELETE /user/address | 地址(写字楼)管理；设置默认 |
| mall | GET /mall/list | 附近/全部美食城 |
| shop | GET /mall/{id}/shops | 美食城内档口列表 |
| dish | GET /shop/{id}/dishes | 档口菜品树（按分类） |
| cart | POST /cart/preview | 跨店拆单预览（起送价/优惠计算） |
| order | POST /order | 下单（跨店拆单）；GET /order（列表，按状态）；GET /order/{id}；POST /order/{id}/cancel；POST /order/{id}/again（再来一单） |
| payment | POST /payment/pay（模拟）；POST /payment/callback（支付回调） | 预留微信策略 |
| comment | POST /comment；GET /shop/{id}/comments | 评价/列表 |
| coupon | GET /coupon/list；POST /coupon/{id}/receive；GET /user/coupons | 可领券/领取/我的券 |
| favorite | POST/DELETE /favorite；GET /favorite | 收藏/取消/列表 |
| merchant | GET/PUT /merchant/shop | 档口信息 |
| merchant | POST/PUT/DELETE /merchant/dish、dish-category | 菜品/分类管理 |
| merchant | GET /merchant/orders；PUT /merchant/order/{id}/accept/prepare/deliver/complete | 接单/备餐/配送/完成 |
| merchant | GET /merchant/comments | 评价查看 |
| merchant | GET /merchant/stat/today | 日营收简单统计 |
